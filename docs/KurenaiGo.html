KurenaiGo ドキュメント

KurenaiGoは、KurenaiEngine (KurenaiEngine2D)を使って実装している囲碁(Go)アプリです。 このドキュメントでは、アプリ本体(KurenaiGo/Source/Main.cpp)の実装内容を説明します。 KurenaiEngine自体のAPIリファレンスは KurenaiEngine/docs/KurenaiEngine.html を参照してください。

1. 現在の実装範囲盤の表示のみ

現時点では19路盤を画面に表示するところまでを実装しています。石を置く操作や対局ルール (着手判定・アゲハマ・地の計算など)は未実装です。

2. 座標系とレイアウト

KurenaiEngine2Dのワールド座標はウィンドウのピクセル座標そのもので、原点は画面左下、 Y-upです(DrawSpriteのx, yはスプライト中心)。KurenaiGoではウィンドウの リサイズに追従できるよう、毎フレーム renderer.GetWidth()/GetHeight() から 盤のレイアウトを再計算しています(ComputeBoardLayout)。 

struct BoardLayout
{
    float CenterX;      // 盤の中心(ウィンドウ中心)
    float CenterY;
    float BoardExtent;  // 木目の盤面の一辺の長さ
    float GridExtent;   // 格子線が占める範囲の一辺の長さ(盤面より内側)
    float LineSpacing;  // 目の間隔 = GridExtent / (kBoardLines - 1)
};
  • BoardExtentはウィンドウの短辺 × kBoardExtentRatio(0.88)。 常に正方形になるよう短辺基準で計算する。
  • GridExtentはBoardExtent × kGridExtentRatio(0.90)。 盤面の外周に木目の縁が見えるよう、格子線の範囲を一回り小さくしている。
  • 格子線のインデックス(0〜18)からワールド座標への変換は GridIndexToCoordinateが行う(中心からGridExtentの半分だけ引いた位置を 起点に、LineSpacing刻みで並べる)。

3. 盤の描画

KurenaiEngine2D::DrawSpriteは矩形(回転可能)のスプライトしか描画できないため、 盤の要素はすべて矩形スプライトの組み合わせで表現しています。円形のテクスチャは使っていません。

要素描画方法
盤面(木目)1x1の白テクスチャを木目色でティントした正方形スプライト1枚
格子線(縦横19本ずつ、計38本)細長い矩形スプライト。横線は幅=GridExtent・高さ=線の太さ、縦線はその逆
星(hoshi、3x3=9箇所)格子の交点(0-indexedで3, 9, 15)に小さな正方形スプライトを配置(円ではなく点の代用)

テクスチャはCreateSolidColorTexture(255, 255, 255, 255)で作成した白1色のテクスチャを 1つだけ使い回し、DrawSpriteのr, g, b, a引数(乗算ティント)で色を出し分けて います(Samples/Sample2Dと同じ手法)。星が正確な円ではなく正方形なのは、 KurenaiEngine2Dには矩形スプライト以外の描画プリミティブがないためで、 石(丸い駒)を描画する段階では実際の円形テクスチャ画像を用意する想定です。

4. 今後の実装予定

  • 石(黒・白)の描画 — 円形のテクスチャ画像を用意し、LoadTextureで読み込んで配置する
  • マウス入力による着手(交点へのスナップ) — KurenaiEngine2D自体は入力を提供しないため、 Win32 APIを直接使う(docs/KurenaiEngine.html 5章参照)
  • 対局ルール(合法手判定・アゲハマ・地の計算・パス/投了)
